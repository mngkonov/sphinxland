Сайт: https://mngkonov.github.io/sphinxland/ · Админка: https://mngkonov.github.io/sphinxland/admin.html

| Файл | Что это |

| `guide.html` | «Как начать»: подключение с ПК и телефона, первая ночь, кланы, торговля, помощь, команды |

## Как включить профили игроков (один раз, ~10 минут)

Регистрация на сайте — по желанию игрока. Пока Supabase не подключён, в кабинете написано «Скоро откроется».

1. Зарегистрируйся на https://supabase.com и создай проект (бесплатный тариф, регион — Frankfurt / ближайший).
2. **SQL Editor → New query** → вставь содержимое `supabase/schema.sql` → **Run**.
3. **Authentication → URL Configuration**:
   - Site URL: `https://mngkonov.github.io/sphinxland/account.html`
   - Redirect URLs: добавь `https://mngkonov.github.io/sphinxland/**`
4. **Authentication → Emails** (по желанию): переведи шаблоны писем на русский.
5. **Project Settings → API**: скопируй **Project URL** и **публичный ключ** (`anon` / `publishable`).
6. Админка → **Основное → Профили игроков** → вставь оба значения → **Опубликовать**.

> ⚠️ Секретный ключ (`service_role` / `sb_secret_…`) на сайт вставлять нельзя — админка не даст его опубликовать.

### Что может администрация

В Supabase → **Table Editor → profiles** можно:
- выдать привилегию: в поле `rank` вписать `scarab`, `priest`, `pharaoh` или `sphinx` (id из раздела «Донат»);
- отметить ник подтверждённым: `verified = true`;
- удалить профиль на чужой ник.

Поля `rank`, `verified`, `stats`, `last_seen` игрок сам изменить не может.

### Статистика с сервера

Профиль уже умеет показывать поле `stats` (JSON): `playtime` (минуты), `joins`, `deaths`, `mob_kills`,
`player_kills`, `blocks_mined`, `blocks_placed`, `distance`, и `last_seen`. Заполнять их будет плагин
на сервере (SiteSync) через секретный ключ — он хранится только на сервере. Скин — поле `skin`, статус — `online`.

## Кланы

Игрок с профилем может создать клан или вступить в чужой. Один игрок — один клан.

- **Клан:** название (3–24 символа), тег (ровно 4 буквы/цифры), описание, пиксельный флаг 8×12 из 16 красителей Minecraft.
- **Вступление:** открытый клан — сразу, закрытый — по заявке (до 5 заявок у игрока одновременно).
- **Роли:** владелец (всё, включая роли и роспуск), офицеры (настройки клана, заявки, исключение участников), участники.
- Если владелец уходит или удаляет аккаунт — клан переходит к офицеру или самому давнему участнику. Пустой клан удаляется.
- Клан, тег и флаг автоматически показываются в профиле и в списке игроков.

Все действия идут через функции базы, напрямую менять таблицы кланов нельзя.
Модерация — Supabase → Table Editor → `clans` (переименовать, удалить).

**После обновления сайта** нужно один раз заново запустить `supabase/schema.sql` в SQL Editor — он добавит кланы
и сохранит существующие профили. Старое текстовое поле «Клан» в профиле удаляется.

## Плагин SiteSync: аккаунт из игры → аккаунт на сайте

Игрок регистрируется на сервере через AuthMe (`/register`) — и у него сразу появляется профиль на сайте.
Входит на сайт **по нику и тому же паролю, что в игре**. Базу AuthMe переносить не нужно: плагин только читает `authme.db`.

**Скачать:** [SiteSync.jar](https://github.com/mngkonov/sphinxland/releases/tag/plugin-latest) — собирается автоматически
(GitHub Actions) при каждом изменении папки `plugin/`. Нужен Paper и AuthMe.

**Установка:**
1. Заново запусти `supabase/schema.sql` в Supabase (добавит поле «профиль из игры» и ники с префиксом Floodgate).
2. Положи `SiteSync.jar` в `plugins/` и перезапусти сервер — появится `plugins/SiteSync/config.yml`.
3. Впиши в `supabase.service-key` **секретный** ключ (Supabase → Project Settings → API Keys → secret / service_role).
   Он хранится только на сервере — на сайт и в Discord его не вставлять.
4. Если у Floodgate другой `username-prefix` — поправь `bedrock-prefix` в конфиге и «Префикс Bedrock-ников» в админке.
5. Введи `/sitesync reload` — ключ подхватится без перезапуска. Проверка: `/sitesync` — статус, `/sitesync sync` — синхронизировать сейчас.

**Что делает плагин:**
- раз в 10 минут читает базу AuthMe (только чтение) и создаёт профили всем зарегистрированным, обновляет «последний раз в игре»;
- при `/register`, `/login`, `/changepassword` сверяет введённый пароль через AuthMe API и ставит такой же пароль на сайте
  (пароль не сохраняется и не пишется в лог, уходит в Supabase по HTTPS);
- профиль из игры сразу отмечен «✓ подтверждён», ник на сайте у него не меняется;
- Bedrock-ники (с префиксом Floodgate) получают платформу Bedrock;
- при входе и выходе игрока (и раз в 10 минут, пока он онлайн) отправляет статус «в игре», **настоящий скин**
  (его подставляет SkinsRestorer — у пиратов будет их скин, а не скин лицензии с тем же ником) и статистику:
  часы в игре, заходы, смерти, мобы, PvP, добытые и поставленные блоки, пройденное расстояние.

**Важно:**
- Игроки, зарегистрированные до установки плагина, получат профиль сразу, а **пароль для сайта — после следующего `/login`** в игре.
- Если ник уже занят профилем, который зарегистрировали на сайте по почте, плагин его не трогает (пишет предупреждение в лог).
- Пароль короче минимума Supabase (по умолчанию 6 символов) сайт не примет — игроку придёт подсказка сменить пароль.
  Минимум можно поменять в Supabase → Authentication → Policies (Password).
